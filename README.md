# Canivete da Roça — Projeto Integrador II (PI2)

Repositório oficial do **Projeto Integrador 2** do grupo para o projeto **Canivete da Roça**.

> 📖 **Consulte as [Diretrizes do Projeto](./DIRETRIZES_DO_PROJETO.md)** para entender a arquitetura técnica (HTML/CSS/JS + Node.js + Supabase), hospedagem, integrações (Pagar.me e Melhor Envio) e divisão de tarefas do grupo.

## 🏗️ Estrutura Monorepo

Este repositório está organizado em formato monorepo contendo os módulos principais:

```text
canivete-da-roca-pi2/
├── backend/       # Código da API e regras de negócio do servidor
├── database/      # Scripts de migração, modelagem e esquemas de banco de dados
└── frontend/      # Aplicação web / interface de usuário
```

## 📁 Diretórios

- **[frontend/](./frontend)**: Interface do usuário da aplicação.
- **[backend/](./backend)**: Serviços e APIs de backend.
- **[database/](./database)**: Modelagem relacional, scripts SQL/DDL, migrations e dados de semente (seed).
